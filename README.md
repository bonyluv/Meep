# Meep

Desarrollo de MEEP, una app para explorar mediciones de pH en alimentos.

## Inicio de sesión

Abre `index.html` para empezar. Desde esa pantalla puedes crear una cuenta o iniciar sesión; al validar los datos, MEEP te lleva a `Aplicación Meep.html`. También está disponible el modo de demostración.

Las cuentas y la sesión se guardan en el almacenamiento local del navegador. Esta versión es un prototipo: no usa un servidor de autenticación y no debe considerarse un sistema seguro para proteger datos sensibles. Para cerrar la sesión, borra los datos locales del sitio en el navegador.
